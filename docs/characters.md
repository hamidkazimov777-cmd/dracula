# ПЕРСОНАЖИ — промты для Nano Banana Pro

## Порядок генерации (важно!)

1. **ВЛАД** — генерим первым. Он становится **эталоном стиля**.
2. Выбираем лучший кадр Влада и дальше **прикрепляем его как образец стиля** ко всем остальным промтам.
3. Остальные по порядку: Нелли → Маркиз → Марк → Парк → Корвин → Старый вампир.
4. Каждого готового персонажа сохраняем во Flow как Character.

Если не прикреплять эталон — каждый персонаж приедет в своём стиле, и сериал развалится.

## Общий блок стиля (одинаковый во всех промтах) — УТВЕРЖДЁН

```
STYLE: hand-drawn 2D cartoon illustration, traditional animation look.
NOT 3D, NOT CGI, NOT Pixar render, NOT photorealistic, NOT anime.
Clean black ink outlines, flat color fill with soft painted shading.
Adult animated comedy series, gothic but warm and inviting.
Rich saturated color, bright and clear, high contrast.
```

**Свет — утверждён:** тёплый янтарный свечной с двух сторон, лицо хорошо освещено
и читается, холодный синий контровой обводит волосы.

**Фон — утверждён:** тёмный готический зал в расфокусе, янтарные свечи по бокам,
синие оконные арки сзади. Только крупные простые формы.

**План — утверждён:** вертикальный 9:16, крупный поясной портрет. Лицо занимает
большую часть кадра. Так Flow запоминает персонажа.

## УРОКИ ПО FLOW (важно)

1. **Кнопка «Создать тело» всегда даёт фотореализм.** Она работает мимо референса.
   Не пользоваться. Тело генерим в Nano Banana Pro и загружаем картинкой.
2. **Flow генерит превью по текстовому описанию, игнорируя стиль аватара.**
   Поэтому в поле «Описание персонажа» ПЕРВОЙ СТРОКОЙ пишем:
   `STYLE: hand-drawn 2D cartoon illustration, NOT photorealistic, NOT 3D, NOT a real person.`
3. **Поле «Настроить производительность» важнее самого голоса.** Без него Flow читает
   реплики с драматическим нажимом и комедия пропадает.
4. **Голос держится, только если персонаж прикреплён к запросу.** В каждой сцене,
   где персонаж говорит, прикрепляем его как Character.
5. **Ничего не давать персонажу в руки на эталоне.** Предмет полезет во все сцены.
   Так было с бокалом у Корвина и камерой у Нелли.

## УРОКИ ПО NANO BANANA PRO

1. «Тёмная палитра» без тёплого света = всё слипается в чёрное пятно.
2. Нахмуренные брови = злодей. Для комедии брови и рот РОВНЫЕ.
3. «round face, full cheeks» = ребёнок. Для взрослой женщины: «oval face,
   slim defined jawline, narrow chin» + прямой запрет child/teenager/baby face.
4. 3D надо запрещать трижды разными словами: NOT 3D, NOT CGI, NOT Pixar render.
5. Размытый готический зал на фоне работает лучше плоской заливки.
6. Чтобы два персонажа были одной породы — прикрепить кадр первого и написать,
   что второй его брат. Чтобы РАЗНЫМИ — не прикреплять и сменить материал и цвет.
